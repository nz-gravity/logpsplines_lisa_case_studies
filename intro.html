Joint gap-aware Gaussian MAP

The seven-day case follows the short-segment, orbit-response idea in Burke et al., Noisy Pipelines I, with an explicit joint covariance for the retained Fourier features. The response determines the moving dips; splines learn the smooth secondary spectra. It is a compact teaching simulation, not a reproduction of the paper’s full instrument and conditioning pipeline.

Install and run the examples, or inspect the code on GitHub. The Back to LogPSplinePSD button remains in the header on every page.
